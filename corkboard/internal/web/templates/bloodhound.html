What gets synced

Computers come from compromised, in-scope hosts with a known fully qualified hostname. Add an explicit mapping below if a host has several names or no matching name.

Accounts are included only when you deliberately record them as owned. A working credential alone does not mark an account owned.

Only the selected identity is sent. Passwords, hashes, notes, and findings stay in Corkboard. Ownership updates are additive; clear ownership in BloodHound when needed.

Record an owned identity

Use the exact BloodHound name or object ID: computer FQDN, account USER@DOMAIN, or SID. Computer mappings require an already compromised host IP.
